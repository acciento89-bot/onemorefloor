# ONE MORE FLOOR v1.44 — Iron Bastion 3D

v1.44 extends the production 3D bridge into the third tower realm.

## Rollout

- floors 1–10: Lower Halls 3D
- floors 11–20: Ossuary 3D
- floors 21–30: Iron Bastion 3D
- floors 31+: stable legacy fallback for now

## Iron Bastion visual kit

The Iron Bastion uses a distinct fortified-industrial language: armored wall bays, riveted metal bands, floor rails and grates, a rear Forge Heart, gear towers, piston towers, hanging chains, warning lamps and ash piles. Lighting moves away from the Ossuary's cold teal/violet palette into hot forge orange, copper and muted warning red.

Animated details are intentionally lightweight: the Forge Heart pulses, gear assemblies rotate and piston towers move subtly. Secondary lights remain non-shadow-heavy so the realm stays suitable for the current mobile rendering target.

## Architecture

The tested 2D gameplay runtime remains authoritative for movement, combat math, collisions, enemy AI, projectiles, rewards, economy, progression and saves. The 3D chamber mirrors runtime state for presentation. The v1.42 optional imported-model pipeline remains active for Wanderer and enemy actor slots.

The realm switch is presentation-only. Lower Halls production details are hidden when Ossuary or Iron Bastion is active, and the Ossuary kit is hidden when Iron Bastion is active.

## Next realm

The next rollout target is Rift Descent, floors 31–40. That pass can replace the current legacy fallback for the fourth realm without changing combat authority.
