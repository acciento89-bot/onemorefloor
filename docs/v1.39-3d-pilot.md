# ONE MORE FLOOR v1.39 — First 3D Chamber

This pass turns the technical menu/navigation split from v1.38 into the first visible 3D gameplay slice.

## Scope

- Floors 1-10 (Lower Halls) render through a real Godot `SubViewport` with a `Node3D` chamber.
- The existing runtime remains authoritative for movement, enemy AI, attacks, damage, drops, progression, saves and touch input.
- Runtime coordinates are mirrored into 3D player, enemy, projectile and coin proxies every frame.
- The first chamber uses an orthographic/isometric `Camera3D`, real directional/omni lighting and real-time shadows.
- The existing 2D combat HUD, joystick, NOVA button, pause/settings/tutorial overlays remain unchanged and are drawn above the 3D arena.
- Floors above 10 deliberately fall back to the existing 2D renderer until their 3D environments are migrated.

## Why this bridge exists

Rewriting gameplay and rendering at the same time would make regressions hard to isolate. This bridge lets the visual world move to 3D now while preserving the tested combat math and iOS touch geometry. Later passes can move collisions/actors/VFX fully into 3D one system at a time.

## Next pass

Replace the placeholder primitive hero/enemy proxies with authored 3D assets and move the Lower Halls chamber from generated primitives to a reusable scene/environment kit while keeping the same runtime synchronization API.
