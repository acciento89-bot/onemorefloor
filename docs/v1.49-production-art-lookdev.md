# ONE MORE FLOOR v1.49 — Production Art & Lookdev

v1.49 moves the 3D tower another step away from prototype presentation without pretending that final external character assets already exist. The current native fallback actors receive another authored detail pass, while a new asset-quality gate makes future rigged GLB imports measurable instead of subjective.

## Scope

- Floors 1–50 remain real 3D through the established shared SubViewport bridge.
- v1.46 camera, realm transitions, boss framing, telegraphs and loot presentation remain active.
- v1.47 production sockets / GLB import contract remains active.
- v1.48 archetype combat VFX and animation presentation remains active.
- Combat math, enemy AI, collision, rewards, XP, economy, progression, saves, touch controls and the 2D HUD/menu stack are unchanged.

## Production asset quality gate

`world3d_asset_quality_v149.gd` defines profiles for all seven actor kinds:

- Wanderer
- Goblin
- Bat
- Skeleton
- Ghoul
- Necromancer
- Warden

Each profile records role, target visual height and practical mobile budgets for mesh nodes, material slots, triangle count and texture memory. Those values are documentation/QA targets; the runtime does not rescale or mutate gameplay from them.

When a real imported actor is present the gate inspects:

- visible mesh nodes,
- material-slot count,
- Skeleton3D presence,
- AnimationPlayer / AnimationTree presence,
- required animation coverage (`idle`, `run`, `attack`),
- recommended animation coverage (`hit`, `skill`, `spawn`, `death`),
- production socket coverage for weapon/head/chest/feet/overhead/VFX.

An imported model only reports `production_candidate` when visible geometry, skeleton, required animation coverage and required sockets are present. Missing or incomplete imports continue to fail safely to the native production actor.

No GLB binaries are fabricated in this change.

## Lookdev layer

The new `ProductionArtLookdev` world layer adds presentation that stays cheap enough for the current mobile target:

- two non-shadow Wanderer lights (rim + fill),
- realm-adaptive rim/fill colors,
- subtle ambient-light grading per realm,
- 18 fixed enemy grounding slots,
- 14 fixed hit-shard burst slots,
- six fixed Wanderer movement echoes,
- boss-only dominance rings and one non-shadow accent light.

No effects are created per frame. Pools are built once with the chamber.

## Realm-adaptive lighting

The player lighting and ambient grade now react to the active tower realm:

- Lower Halls — purple rim / warm gold fill,
- Ossuary — teal rim / cold pale fill,
- Iron Bastion — forge orange rim / copper-gold fill,
- Rift Descent — magenta rim / cyan fill,
- Starless Spire — blue rim / pale celestial fill.

This helps the same actor materials sit naturally inside all five environments without adding expensive per-realm material variants.

## Grounding and hit response

Elite enemies, Wardens, active attack tells and persistent casters receive subtle floor grounding. Hit-stamp transitions emit a pooled archetype-colored five-shard burst at the actor chest socket. The Wanderer leaves restrained rune echoes while moving quickly enough to communicate direction without becoming a particle cloud.

## Boss dominance

On floors 10/20/30/40/50, a visible Warden gets an additional boss-only floor layer with:

- two rotating dominance rings,
- eight floor markers,
- one pulsing local accent light.

This sits underneath the existing v1.46 boss crown/beam system instead of replacing it.

## Real-asset handoff

The intended next real art handoff is unchanged: place real rigged actor files in the documented actor slots under `assets/models/actors/`. v1.49 makes that handoff easier to validate because the runtime can now report whether the imported asset meets the socket/skeleton/animation contract.

Until those source assets exist, the native stylized actors remain deliberately available as a safe fallback rather than pretending procedural geometry is final production character art.
