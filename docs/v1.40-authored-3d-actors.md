# ONE MORE FLOOR v1.40 — Authored 3D Actors

This pass replaces the first 3D chamber's capsule placeholders with authored stylized low-poly silhouettes built from native Godot meshes.

## Included

- Wanderer 3D body with hood, recessed face, cloak/cape, armor, pauldrons, boots, glowing sword and NOVA ring.
- Distinct early-floor silhouettes for goblin, bat, skeleton, ghoul, necromancer and the floor warden.
- Type-specific weapons, faces, ears/wings/bones/robes/armor and emissive details.
- Movement, attack, hit/tell and wing/cape animation language driven from the existing runtime state.
- Lower Halls floor seams, gate bars, threshold and rune-lit pillars for stronger depth/readability.
- No changes to combat math, collisions, enemy AI, rewards, economy, save schema or mobile input geometry.

The actors remain self-contained procedural meshes for now. The next asset pass can replace these nodes with rigged production models without changing the 2D-runtime-to-3D synchronization contract.
