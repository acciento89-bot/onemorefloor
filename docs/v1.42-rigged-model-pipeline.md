# ONE MORE FLOOR v1.42 — Rigged Production Model Pipeline

v1.42 creates the stable bridge from the current native Godot-built 3D actors to imported production character models.

## What changes

- seven explicit production actor slots: Wanderer, Goblin, Bat, Skeleton, Ghoul, Necromancer and Warden
- optional `.glb` loading with automatic native fallback
- persistent `Motion/RigMount` on player and configured enemies
- generic `AnimationPlayer`/`AnimationTree` state driving for idle, run, attack, hit and skill
- imported models remain presentation-only and inherit the existing runtime actor root
- dedicated v1.42 smoke test and CI

## What does not change

Combat math, enemy AI, runtime positions, hitboxes, rewards, economy, saves, progression, touch controls, 3D chamber lighting and the v1.41 VFX stack remain authoritative and unchanged.

## Model replacement workflow

Drop a compatible production GLB into `assets/models/actors/` using one of the documented filenames. The registry detects it through `ResourceLoader`, mounts it under the existing actor root and hides the native geometry while retaining combat tells, hit flashes and world grounding.

Until real production GLBs are committed, every actor continues to use the v1.41 native production fallback. This lets the rendering/runtime architecture land safely before external art is introduced.

## Next milestone

With the actor import contract stable, the next 3D content milestone is the Ossuary environment kit for floors 11–20 and the first imported rigged Wanderer model when final art is available.
