# ONE MORE FLOOR — Game Design v0.1

## Fantasy

A fast mobile roguelite about pushing an endless tower one floor further than you should.

## Core promise

Every cleared floor creates a real decision: lock in the loot or risk the run for a stronger reward.

## Core loop

1. Enter a compact combat floor.
2. Move and dodge while the hero auto-attacks.
3. Clear the enemy wave.
4. Choose one of three temporary run upgrades.
5. Cash out or choose **ONE MORE FLOOR**.
6. Spend secured currency on permanent progression in the camp.

## Vertical slice

The first slice deliberately uses procedural placeholder graphics so gameplay can be tuned before production art is locked.

Included:

- Portrait-first mobile layout
- Touch joystick
- Auto-targeting attacks
- Enemy pursuit and contact damage
- Every fifth floor becomes a boss floor
- Three-choice upgrade screen
- Cash-out vs. continue decision
- Death penalty on unsecured run coins
- Local best-floor and coin persistence
- Desktop mouse/WASD fallback for quick testing

## Initial balancing targets

- Standard floor: 20–45 seconds
- Boss floor: 45–75 seconds
- First meaningful build synergy: by floor 4–6
- Typical first-session run: 5–10 minutes

## Art direction

Dark fantasy with modern mobile-game readability:

- Deep navy / purple world tones
- Warm gold interaction accents
- Bright ability colors
- Chunky readable silhouettes
- Minimal text during combat
- Strong contrast for one-handed portrait play
